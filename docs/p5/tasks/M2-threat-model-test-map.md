# M2 Unix-socket IPC threat-to-test map (spike entry criteria)

Scope: Linux local Unix-domain socket between the device agent and the presentation renderer. The renderer displays state and sends user-control requests; it does not receive authority to execute tools, grant permissions, or mutate canonical state. Socket IPC is a local transport, not an authentication substitute for policy checks.

**Status:** M2 implementation remains in progress on `feat/p5-m2-ipc-spike`; IPC-01 remains Not Run. Development baseline: the repository's pinned Ubuntu 24.04 CI runner and Rust 1.99.1; this does not claim a supported desktop distribution/profile. `crates/lia-device-agent/src/ipc.rs` implements bounded 4-byte big-endian framing, strict JSON envelope/method/UUID validation, duplicate-key rejection, strict typed user-event bodies, deadline validation, private endpoint creation/cleanup, Linux `SO_PEERCRED`, a hello → ready state machine, UID/PID-bound listener negotiation under one absolute monotonic deadline, a multi-connection accept loop, reconnect snapshots, one-slot monotonic snapshot coalescing, a bounded queue of typed `UntrustedUserIntent` values, and a supervised child-process test primitive. P4 package 0.3.2 now defines and validates strict hello, ready and state-replacement body schemas, including unknown-field and fabricated-outcome rejection. Session/deadline/sequence checks return events only for caller policy evaluation; transport code does not authorize or dispatch them.

Still open for M2 exit: bind the production renderer process and independently restartable service lifecycle; define and exercise the authorization boundary without granting the renderer execution authority; test slow readers and sustained concurrent flood/resource high-water bounds beyond the synthetic local stress profile; coverage-guided fuzzing; and complete IPC-01 evidence/review. A local endpoint-recreation test now verifies that the old socket path is removed, a new endpoint can bind the same path, a fresh session is issued and an event bearing the previous session ID is rejected. This recreates endpoint ownership within one test process; it does not prove process crash recovery or production service supervision. A mapped-user-namespace test reaches `accept()` from a distinct UID over an intentionally reachable disposable endpoint and verifies kernel credential rejection before frame parsing; production permissions remain 0700/0600. Existing evidence is partial. The full IPC-01 gate and all P4 implementation gates remain Not Run. Namespace, race-cleanup, deterministic mutation-smoke and local latency evidence remain supplemental and do not establish the gate.

| Threat / assumption | Required control | Test and evidence |
| --- | --- | --- |
| Attacker pre-creates or swaps the socket path | Private runtime directory; reject symlink/non-socket; create with restrictive mode; safe cleanup tied to inode | **Partial unit coverage:** non-private parent, symlink parent, pre-existing regular file and symlink endpoint are rejected; mode 0600 and cleanup preserving a replacement inode are checked. Foreign-owner rejection and a deterministic parent-directory swap race are tested; probabilistic race stress remains open |
| Other local user or same-UID process connects | Check `SO_PEERCRED` UID and PID against values supplied by the renderer supervisor; never trust claimed identity in payload | **Partial unit coverage:** mismatched expected UID/PID are rejected before an invalid frame is parsed; a same-UID sibling process is rejected against the expected PID. A mapped-user-namespace test reaches `accept()` from a distinct UID over a temporary permissive endpoint and is rejected by kernel credentials; a separate path test verifies the production 0700 directory blocks that UID. Production renderer-supervisor integration in Godot and forged JSON identity case remain open |
| Same-user process impersonates renderer | Peer UID/PID checks depend on a trusted supervisor; bind accepted PID to the renderer instance and authorize every control | **Partial primitive coverage:** a sibling process under the same UID is rejected when its PID differs from the expected PID. The new local `RendererSupervisor` binds the launched child PID and applies bounded restart/backoff; integration with the eventual Godot renderer remains open. Authorization dispatch tests remain open; current code has no state-changing handler |
| Frame is malformed, oversized, truncated or has trailing bytes | Length-prefixed bounded frames; strict JSON/schema; one complete frame per message | **Partial unit coverage:** zero/oversized, truncated header/body, invalid UTF-8/JSON, trailing JSON, duplicate keys, unknown fields, invalid method/version/kind, uint64 sequence overflow, malformed user-event schemas and oversized text are rejected. A deterministic 50,000-case mutation smoke is retained; coverage-guided fuzz and resource-bound procedures remain open |
| Client disconnects during a write or reply | Per-connection state is disposable; canonical operation outcome remains in the store | **Partial unit coverage:** disconnect mid-header and mid-body returns EOF; handshake timeout shuts down the connection. Snapshot delivery is checked on a live ready session. Snapshot send detects a disconnected peer and the accept loop returns to listening. Query-current-state behavior and integration with real renderer replies remain open |
| Renderer or agent endpoint restarts, or sends stale state/control sequence | Session-bound monotonically increasing sequence for IPC controls; stale snapshot revision cannot overwrite newer state; endpoint cleanup allows safe rebind | **Partial unit coverage:** first zero, forward increase, duplicate/backward, and cross-session user-event frames are rejected. A socket-pair listener test verifies a reconnect issues a fresh session and rejects an old ready frame. A local accept-loop reconnect test receives a new session and snapshot; a test child is relaunched with a refreshed PID. A separate endpoint-recreation test confirms the old path is removed, the same path can be rebound, a new session is issued and an old-session event is rejected. These tests use one process and do not prove process crash recovery or Godot integration; process-level service supervision and generation wiring remain open |
| Slow reader or message flood exhausts resources | Backpressure, bounded queues, read/write deadlines, per-peer quotas | **Partial evidence:** a slow-drip hello cannot extend one absolute monotonic deadline; a 64-frame user-event flood against a capacity-2 queue terminates the session at the queue bound (2 queued; the next event rejected). The accept loop now waits on listener readiness with `poll(2)` rather than sleeping between empty polls; a stop-while-idle test verifies bounded shutdown. A local stress example follows a burst of 64 disconnected peers with 128 healthy reconnect/snapshot cycles. Across three post-change runs, handshake P95 was 0.116–0.155 ms, observed FD count stayed 5–6 and process RSS high-water ended at 3,072–3,084 KiB. These synthetic sequential measurements do not cover a slow reader, simultaneous healthy and abusive clients, sustained load or a target resource budget; those remain open |
| Network exposure accidentally appears | Bind only `AF_UNIX`; no TCP listener or remote fallback | Inspect open/listening sockets and configuration; assert no TCP listener in test process |
| Renderer message attempts to claim operation success | Agent emits outcome; renderer may request controls only from explicit allowlist | **Partial parser coverage:** user-event `outcome`/unknown fields are rejected. Snapshot-derived UI and authorization dispatch are not implemented; test those in IPC-01/GODOT-01 |

The initial development baseline uses Ubuntu 24.04 because that is the repository CI runner; this does not select a desktop distribution or claim support. The 262,144-byte maximum and protocol version 1 come from the draft P4 IPC contract. Socket parent policy is exactly 0700 owner-only; socket mode is 0600. Socket creation pins the validated parent directory FD, binds/unlinks through `/proc/self/fd`, applies mode with `fchmodat2(AT_SYMLINK_NOFOLLOW)`, and rejects a parent replacement detected during setup; deterministic parent and endpoint swap tests verify cleanup and prevent following a raced symlink. A namespace test reaches `accept()` as a distinct UID over an intentionally permissive disposable endpoint and verifies `SO_PEERCRED` rejection before parsing; the production path remains private. The accept loop's supervisor primitive binds UID/PID to its launched child and refreshes the PID with bounded restart/backoff; wiring it to the eventual Godot process remains open. P4 package revision 0.3.2 defines strict hello/ready/state-replacement bodies in addition to the user-event schema. A matching non-expired ready report is required before user events; those events carry a canonical decimal `session_sequence` beginning at zero and strictly increasing per live connection. Expired hello/ready reports do not activate the connection; expired user events do not consume sequence. Reconnect discards the old session ID and watermark. These checks reject stale/reordered frames but do not authorize controls; state-changing dispatch remains disabled pending the approved UI action registry and current policy checks. Preserve test traces and hashes as IPC-01 evidence; all gates remain Not Run until the complete matrix is executed against the implementation.
