# M2 Unix-socket IPC threat-to-test map (spike entry criteria)

Scope: Linux local Unix-domain socket between the device agent and the presentation renderer. The renderer displays state and sends user-control requests; it does not receive authority to execute tools, grant permissions, or mutate canonical state. Socket IPC is a local transport, not an authentication substitute for policy checks.

**Status:** M2 implementation remains in progress on `feat/p5-m2-ipc-spike`; IPC-01 remains Not Run. Development baseline: the repository's pinned Ubuntu 24.04 CI runner and Rust 1.99.1; this does not claim a supported desktop distribution/profile. `crates/lia-device-agent/src/ipc.rs` implements bounded 4-byte big-endian framing, strict JSON envelope/method/UUID validation, duplicate-key rejection, strict typed user-event bodies, deadline validation, private endpoint creation/cleanup, Linux `SO_PEERCRED`, a hello → ready state machine, UID/PID-bound listener negotiation under one absolute monotonic deadline, a one-second hard I/O timeout ceiling, a multi-connection accept loop, reconnect snapshots, one-slot monotonic snapshot coalescing, a bounded queue of typed `UntrustedUserIntent` values, and a supervised child-process test primitive. P4 package 0.3.3 now defines and validates strict hello, ready and state-replacement bodies, immediate close on malformed frames, and the one-second I/O cap. Session/deadline/sequence checks return events only for caller policy evaluation; transport code does not authorize or dispatch them.

Still open for M2 exit: complete production service supervision and Godot process integration; sustained multi-hour resource load testing; and final IPC-01 gate execution and review. The presentation authorization boundary now includes a production UI action registry (`ProductionUiRegistry`) defining canonical AC-010 controls with risk tiers (R0, R1), allowed event kinds, text bounds, and session freshness; and a deterministic presentation policy evaluator integrated with permission authority checks; see [18 November authorization and lifecycle evidence](../../../evidence/IPC-01/2026-11-18-m2-production-authorization-and-lifecycle/README.md). The renderer supervisor now includes graceful SIGTERM termination with bounded timeout fallback to SIGKILL, child status inspection (`is_alive`, `restart_count`), and clean zombie-free child reaping on Drop. An isolated 32-cycle connection churn test verifies zero file descriptor leaks and bounded memory; slow reader snapshot delivery respects the 1.0s timeout ceiling; and adversarial parser edge cases (deeply nested objects, control ID syntax/length, invalid float intensities) are verified rejected. A 60-second isolated libFuzzer run over four synthetic frames completed 4,010,078 inputs (65,738/s average, 5,457 new units, 504 MiB peak RSS) without a crash artifact; a five-minute run completed 19,261,140 inputs (63,990/s average, 8,157 new units, 434 MiB peak RSS) without a crash artifact. The five-minute run replayed its generated corpus through coverage instrumentation, reporting 22.41% line coverage in `ipc.rs`; this fixed-corpus replay was not fuzzing and no threshold is set. See [five-minute parser fuzz evidence](../../../evidence/IPC-01/2026-11-17-m2-coverage-guided-fuzz-5m/README.md) and the [60-second run](../../../evidence/IPC-01/2026-11-17-m2-coverage-guided-fuzz/README.md). These parser-only results do not prove service behavior, resource budgets or conformance. The renderer supervisor now has a synthetic child-process check covering three bounded restarts with 50/100/200 ms backoff and fail-closed exhaustion; see [restart-budget evidence](../../../evidence/IPC-01/2026-11-17-m2-renderer-restart-budget/README.md). It still does not prove Godot integration or production service supervision. A local endpoint-recreation test now verifies that the old socket path is removed, a new endpoint can bind the same path, a fresh session is issued and an event bearing the previous session ID is rejected. This recreates endpoint ownership within one test process; it does not prove process crash recovery or production service supervision. A mapped-user-namespace test reaches `accept()` from a distinct UID over an intentionally reachable disposable endpoint and verifies kernel credential rejection before frame parsing; production permissions remain 0700/0600. Existing evidence is partial. The full IPC-01 gate and all P4 implementation gates remain Not Run. Namespace, race-cleanup, deterministic mutation-smoke and local latency evidence remain supplemental and do not establish the gate.

Query-current-state behavior and integration with real renderer replies remain open |
| Renderer or agent endpoint restarts, or sends stale state/control sequence | Session-bound monotonically increasing sequence for IPC controls; stale snapshot revision cannot overwrite newer state; endpoint cleanup allows safe rebind | **Partial unit coverage:** first zero, forward increase, duplicate/backward, and cross-session user-event frames are rejected. A local accept-loop reconnect test receives a new session and snapshot; a test child is relaunched with a refreshed PID. A separate endpoint-recreation test confirms the old path is removed, the same path can be rebound, a new session is issued and an old-session event is rejected. The accept loop waits on listener readiness with `poll(2)`; an isolated 32-cycle connection churn test verifies zero FD leaks and bounded memory; an accept-loop stress benchmark confirms 128 reconnects under a 64-connection burst with FD count staying at baseline + 1 and RSS under 4 MiB. Full multi-hour sustained load and production service budget tests remain open |

Snapshot-derived UI, production registry/policy integration, and authorization dispatch are not implemented; test those in IPC-01/GODOT-01 |

The initial development baseline uses Ubuntu 24.04 because that is the repository CI runner; this does not select a desktop distribution or claim support. The 262,144-byte maximum and protocol version 1 come from the draft P4 IPC contract. Socket parent policy is exactly 0700 owner-only; socket mode is 0600. Socket creation pins the validated parent directory FD, binds/unlinks through `/proc/self/fd`, applies mode with `fchmodat2(AT_SYMLINK_NOFOLLOW)`, and rejects a parent replacement detected during setup; deterministic parent and endpoint swap tests verify cleanup and prevent following a raced symlink. A namespace test reaches `accept()` as a distinct UID over an intentionally permissive disposable endpoint and verifies `SO_PEERCRED` rejection before parsing; the production path remains private. The accept loop's supervisor primitive binds UID/PID to its launched child and refreshes the PID with bounded restart/backoff; wiring it to the eventual Godot process remains open. P4 package revision 0.3.3 defines strict hello/ready/state-replacement bodies in addition to the user-event schema. A matching non-expired ready report is required before user events; those events carry a canonical decimal `session_sequence` beginning at zero and strictly increasing per live connection. Expired hello/ready reports do not activate the connection; expired user events do not consume sequence. Reconnect discards the old session ID and watermark. These checks reject stale/reordered frames but do not authorize controls; state-changing dispatch remains disabled pending the approved UI action registry and current policy checks. Preserve test traces and hashes as IPC-01 evidence; all gates remain Not Run until the complete matrix is executed against the implementation.
