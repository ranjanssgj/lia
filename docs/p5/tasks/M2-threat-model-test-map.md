# M2 Unix-socket IPC threat-to-test map (spike entry criteria)

Scope: Linux local Unix-domain socket between the device agent and the presentation renderer. The renderer displays state and sends user-control requests; it does not receive authority to execute tools, grant permissions, or mutate canonical state. Socket IPC is a local transport, not an authentication substitute for policy checks.

**Status:** M2 spike in progress on `feat/p5-m2-ipc-spike`. Development baseline: the repository's pinned Ubuntu 24.04 CI runner and Rust 1.99.1; this does not claim a supported desktop distribution/profile. `crates/lia-device-agent/src/ipc.rs` currently implements bounded 4-byte big-endian framing, strict JSON envelope/method validation, duplicate-key rejection, deadline validation, private endpoint creation/cleanup, and Linux `SO_PEERCRED` checks. The full bridge and IPC-01 remain Not Run. See [partial local evidence](../../../evidence/IPC-01/2026-11-15-m2-spike/README.md).

| Threat / assumption | Required control | Test and evidence |
| --- | --- | --- |
| Attacker pre-creates or swaps the socket path | Private runtime directory; reject symlink/non-socket; create with restrictive mode; safe cleanup tied to inode | **Partial unit coverage:** non-private parent and pre-existing regular file rejected, mode 0600 and cleanup inode checked. Symlink swap, foreign owner, and concurrent path race remain open |
| Other local user connects | Check `SO_PEERCRED` UID against agent's expected user; never trust claimed PID/UID in payload | **Partial unit coverage:** kernel UID/PID is read and mismatched expected UID is rejected. Separate-UID process test and forged JSON identity case remain open |
| Same-user process impersonates renderer | Peer UID is not renderer identity or authorization; require an agent-issued session/capability for allowed controls | Same-UID client sends privileged/unknown request; deny; demonstrate no permission or adapter call |
| Frame is malformed, oversized, truncated or has trailing bytes | Length-prefixed bounded frames; strict JSON/schema; one complete frame per message | **Partial unit coverage:** zero/oversized, truncated body, invalid UTF-8/JSON, duplicate keys and unknown fields rejected. Truncated header, invalid method/version/kind, trailing JSON, and fuzz/resource-bound procedures remain open |
| Client disconnects during a write or reply | Per-connection state is disposable; canonical operation outcome remains in the store | Disconnect at header/body/reply points; restart renderer and query current state without replaying effects |
| Renderer restarts or sends stale state/control sequence | Session-bound monotonically increasing sequence for IPC controls; stale snapshot revision cannot overwrite newer state | Reconnect, replay prior sequence/revision, out-of-order update; reject stale data and preserve current state |
| Slow reader or message flood exhausts resources | Backpressure, bounded queues, read/write deadlines, per-peer quotas | Stop reading, flood valid/invalid frames, exceed queue cap; verify bounded RSS/FDs and responsiveness of healthy client |
| Network exposure accidentally appears | Bind only `AF_UNIX`; no TCP listener or remote fallback | Inspect open/listening sockets and configuration; assert no TCP listener in test process |
| Renderer message attempts to claim operation success | Agent emits outcome; renderer may request controls only from explicit allowlist | Attempt fabricated success/evidence and forbidden method; ensure UI state derives only from agent snapshot/outcome |

The initial development baseline uses Ubuntu 24.04 because that is the repository CI runner; this does not select a desktop distribution or claim support. The 262,144-byte maximum and protocol version 1 come from the draft P4 IPC contract. Socket parent policy is 0700 owner-only; socket mode is 0600. The expected UID check does not authenticate a specific same-UID renderer: session binding/capability design and same-user threat handling remain open before authorization-sensitive controls are exposed. Preserve test traces and hashes as IPC-01 evidence; all gates remain Not Run until the complete matrix is executed against the implementation.
